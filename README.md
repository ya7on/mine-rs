# mine-rs

This project is an implementation of the Minecraft Java Edition server protocol in Rust.

Supported Minecraft version: **26.3**

Protocol version: **777**

Crates:

- `crates/mclib` — shared protocol types and codecs (see `docs/crates/mclib/`).
- `crates/server` — minimal status-only server (see `docs/crates/server/`).
